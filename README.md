# GIZ OLACEFS

Repositorio monorepo con las matrices y sistema visual de GIZ OLACEFS.

## Estructura

- **Matriz de cumplimiento/**: Validación de la Matriz de Cumplimiento.
- **Matriz de desempeño/**: Matriz de Desempeño.
- **Matriz financiera/**: Matriz Financiera.
- **Sistema visual/**: Componentes y sistema de diseño de referencia.

## Despliegue en Netlify

Cada carpeta funciona como un sitio independiente configurando el **Base directory** correspondiente en Netlify sin comando de compilación (Build command en blanco).
